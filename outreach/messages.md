# Шаблони листів (українською)

Плейсхолдери **не замінюйте вручну в кожному листі**. Заповніть один раз `.env` (`OUTREACH_NAME`, `OUTREACH_EMAIL`, `OUTREACH_GITHUB`, `OUTREACH_DEMO1`, `OUTREACH_DEMO2`) — `npm run outreach:dry-run` підставить їх у CSV-листи.

Якщо копіюєте шаблон нижче в Gmail вручну — тоді так, підставте значення самі або візьміть уже зібраний текст із dry-run.

Профіль: **AI agent builder / automation**, тільки **remote**, без комерційного досвіду — акцент на демо, не на «ML Engineer 3+ years».

---

## 1. Відгук на конкретну remote-вакансію

**Тема:** `[РОЛЬ] — AI agent builder (remote) | [ІМʼЯ]`

**Тіло:**

```
Доброго дня!

Мене звати [ІМʼЯ]. Відгукуюсь на вакансію «[РОЛЬ]» ([URL]). Працюю з AI-агентами та автоматизацією на LLM: прототипи агентів, інтеграції інструментів, RAG-сценарії.

Комерційного досвіду в продуктовій компанії ще немає — є публічні демо:
• [DEMO1]
• [DEMO2]
GitHub: [GITHUB]

Шукаю саме remote. Готовий(а) до тестового завдання або короткого дзвінка. Відповісти можна на [EMAIL].

Дякую за розгляд,
[ІМʼЯ]
```

EN (опційно, в кінці того ж листа):

```
EN: Junior AI agent builder (remote only). Portfolio: [GITHUB]. Happy to do a take-home or a short call.
```

## 2. Open application (Дія / AICoE / Мінцифра)

**Тема:** `Open application — Junior AI agent builder (remote) | [ІМʼЯ]`

**Тіло:**

```
Доброго дня, командо [ОРГАНІЗАЦІЯ]!

Мене звати [ІМʼЯ]. Хочу долучитися до цифрової держави як junior / стажер у напрямку AI-агентів і автоматизації (не senior ML).

Що можу показати вже зараз:
• агентські прототипи та tooling навколо LLM — [DEMO1]
• ще один кейс — [DEMO2]
• код: [GITHUB]

Готовий(а) до стажування або junior-ролі з чітким менторством. Формат роботи — лише remote. Якщо зараз немає відповідної позиції — буду вдячний(а) за open application / reserve list.

Контакт: [EMAIL]

З повагою,
[ІМʼЯ]
```

## 3. Холодне підряднику на держпроєкти (GovTech)

**Тема:** `Junior AI tooling / agent automation (remote) — інтерес до ваших держпроєктів`

**Тіло:**

```
Доброго дня!

Пишу в Kitsoft / SoftServe / … (підставте назву): бачу ваш досвід у цифровій державі та GovTech. Шукаю remote junior-роль або стажування в AI tooling / agent automation (LLM-агенти, автоматизація процесів, інтеграції).

Портфоліо:
• [DEMO1]
• [DEMO2]
• [GITHUB]

Комерційного досвіду немає — компенсую швидкими демо та готовністю до тестового. Якщо в командах на держцифри є місце під junior AI — буду радий(а) короткому знайомству.

[ІМʼЯ] | [EMAIL]
```

## Що не писати

- «Як AI я заміню команду…»
- Перебільшений senior ML / research профіль
- Масовий spam на випадкові `@gov.ua`
- Прохання про бронювання / допуск як перший меседж
